# Loads the Parent Step of One Step, Not Applicable to Multiple Steps

Loads the Parent Step of One Step, Not Applicable to Multiple Steps

## Usage

``` r
loadParentStep(ident, from = pwd())
```

## Arguments

- ident:

  resourceID, entityId or path to the step.

- from:

  path working directory, default is the calling step

## Value

parent step as DF
