# List All Groups

Retrieves a list of all groups in the improve repository.

## Usage

``` r
loadGroups()
```

## Value

A data frame of groups. Returns `NULL` if the groups cannot be
retrieved.

## See also

[`loadGroup`](https://improverse.github.io/improveR/reference/loadGroup.md),
[`loadGroupUsers`](https://improverse.github.io/improveR/reference/loadGroupUsers.md)

## Examples

``` r
if (FALSE) { # \dontrun{
groups <- loadGroups()
} # }
```
